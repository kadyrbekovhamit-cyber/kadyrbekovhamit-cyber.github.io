How a tool earns a recommendation

The aim is useful purchasing evidence, not promotional copy. Firsthand use is labelled as testing; documentation-only work is labelled as an evidence review.

1. Define the jobWho is the tool for, and what measurable task should it complete?
2. Collect evidenceOfficial specifications, pricing, policies, and reproducible tests where available.
3. Record limitsMissing features, lock-in, hidden effort, uncertainty, and who should not buy.
4. Publish correctionsMaterial errors are logged and corrected instead of silently disappearing.
