Make scoring decisions visible before intervention.

QALQON combines traffic patterns, reputation signals and message rules into an explainable risk index. This preview records how a bounded local evaluation handled ordinary traffic, a legitimate lookalike and suspicious wording.

Synthetic local evaluation. These are saved observations, not a live service. In the recorded default mirror mode, the returned action stays allow while a separate advisory remains visible. Scores are heuristic indices, not probabilities.

Current readiness

Controlled evaluation; further engineering required

Testing used synthetic inputs, built-in development parameters and built-in rules. Authentication, licensing, live HTTP behaviour and carrier integration were not tested. No detection accuracy, fraud reduction, throughput or production latency has been established.

An input-boundary repair is proposed and remains under review. The original project must be hardened before deployment. Representative operator data, language coverage, false-positive review, security and integration acceptance are still required; this preview does not establish production readiness.
